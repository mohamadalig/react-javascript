Loja Shop — فروشگاه اینترنتی


فروشگاه اینترنتی Loja Shop یک پروژه نمونه با استفاده از React، Vite و Redux Toolkit است که با هدف تمرین توسعه وب و ارائه در نمونه‌کار (Portfolio) طراحی شده است.

این پروژه شامل رابط کاربری دوزبانه فارسی و انگلیسی، پشتیبانی از حالت روشن و تاریک، طراحی الهام‌گرفته از فروشگاه‌های اینترنتی مانند دیجی‌کالا و امکان اتصال به بک‌اند Supabase است.



✨ ویژگی‌ها



🛍️ محصولات: بیش از ۱۰۰ محصول در ۳ دسته‌بندی، همراه با گالری تصاویر، قیمت و تخفیف
🏠 صفحه اصلی: اسلایدر، پیشنهادهای ویژه، دسته‌بندی‌های تصویری و ردیف‌های اسکرولی محصولات
🔎 جستجو و فیلتر: فیلتر بر اساس دسته‌بندی، قیمت و امتیاز، به همراه مرتب‌سازی محصولات
🛒 سبد خرید: مدیریت سبد خرید با Redux Toolkit
📦 جزئیات محصول: صفحه اختصاصی محصول همراه با تب‌ها و بخش نظرات
🔐 احراز هویت: ثبت‌نام و ورود همراه با اعتبارسنجی و امکان اتصال به Supabase Auth
📊 داشبورد مدیریت: بخش سفارش‌ها، درآمد و مدیریت محصولات
💬 چت زنده: امکان پیاده‌سازی گفت‌وگوی بلادرنگ با Supabase Realtime
💳 پرداخت آنلاین: ساختار اتصال به درگاه زرین‌پال با استفاده از Supabase Edge Functions
🌐 پشتیبانی دوزبانه: زبان‌های فارسی و انگلیسی با چیدمان RTL و LTR
🌓 قالب ظاهری: حالت روشن و تاریک



🚀 راه‌اندازی پروژه
پیش‌نیازها



برای اجرای پروژه به Node.js و npm نیاز دارید.



نصب وابستگی‌ها
bash
npm install

اجرای محیط توسعه
bash
npm run dev




پس از اجرا، آدرس محلی نمایش‌داده‌شده در ترمینال را در مرورگر باز کنید. آدرس پیش‌فرض Vite معمولاً به صورت زیر است:



http://localhost:5173

🗄️ اتصال به Supabase



برای فعال‌سازی قابلیت‌های بک‌اند، مراحل زیر را انجام دهید:

۱. در Supabase یک پروژه ایجاد کنید.

۲. فایل supabase/schema.sql را در بخش SQL Editor اجرا کنید. این اسکریپت برای ایجاد جداول و داده‌های اولیه طراحی شده است.

۳. در ریشه پروژه، کنار فایل package.json، یک فایل با نام .env ایجاد کنید.

۴. مقادیر اتصال را در فایل .env قرار دهید:



env
VITE_SUPABASE_URL=https://xxxx.supabase.co
VITE_SUPABASE_ANON_KEY=YOUR_SUPABASE_ANON_KEY



مقادیر نمونه را با اطلاعات واقعی پروژه Supabase خود جایگزین کنید.

۵. سرور توسعه را متوقف و دوباره اجرا کنید:



bash
npm run dev



نکته امنیتی: فایل .env را در GitHub منتشر نکنید. همچنین برای اطلاعات حساس مدیریتی، از کلیدهای دارای دسترسی بالا در کد سمت کاربر استفاده نکنید. سیاست‌های دسترسی پایگاه داده (RLS) باید متناسب با نیازهای پروژه تنظیم شوند.



💳 راه‌اندازی درگاه پرداخت زرین‌پال (اختیاری)



برای استقرار تابع پرداخت، در صورت پیاده‌سازی و آماده بودن تنظیمات مربوطه، مراحل زیر را دنبال کنید.

۱. نصب ابزار Supabase CLI



bash
npm install -g supabase

۲. ورود و اتصال به پروژه
bash
supabase login
supabase link --project-ref=YOUR_PROJECT_REF

۳. تنظیم شناسه پذیرنده
bash
supabase secrets set ZARINPAL_MERCHANT_ID=YOUR_MERCHANT_ID

۴. استقرار تابع پرداخت
bash
supabase functions deploy zarinpal




شناسه پذیرنده را از حساب زرین‌پال خود دریافت کنید. مقادیر حساس را فقط در تنظیمات امن سمت سرور یا Secrets نگهداری کنید، نه در کد فرانت‌اند.

توجه: فعال شدن پرداخت واقعی به پیاده‌سازی کامل تابع پرداخت، تنظیمات درگاه و بررسی پاسخ‌های پرداخت وابسته است.

🔑 حساب آزمایشی مدیریت



در صورت فعال بودن حساب آزمایشی در نسخه فعلی پروژه، اطلاعات ورود به صورت زیر است:

ایمیل: admin@shop.com
رمز عبور: admin123

این اطلاعات صرفاً برای آزمایش محلی هستند. پیش از انتشار عمومی، از فعال بودن این حساب در محیط واقعی اطمینان حاصل کنید و در صورت نیاز آن را غیرفعال کنید.
